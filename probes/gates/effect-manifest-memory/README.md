# Effect manifest memory regression

Run on Windows with the SDK compiler built from the current checkout:

```powershell
./probes/gates/effect-manifest-memory/run.ps1 -Compiler ./bootstrap_compiler/out/vyxc.exe
```

The gate compiles the current manifest implementation as project source and
runs its native AOT output. It checks empty rows, duplicate rows, Unicode,
missing final newlines, and a descending set of 512 long records against an
independently generated byte-sorted result. Execution is limited to 256 MiB
private commit by a Windows Job. Building has a separate 4 GiB limit.

The large fixture covers repeated substring/remaining-text copies in manifest
sorting. Compiler and executable identity, commands, wall time, resident samples,
and private commit peaks are saved under the ignored `.runs/` directory.
`-ManifestSource` selects a historical source file for a controlled comparison;
normal acceptance uses the source in this checkout.
