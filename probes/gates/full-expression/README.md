# 完整表达式的对象生命周期

使用本次构建的 SDK 编译器执行：

```powershell
python probes/gates/full-expression/run.py --compiler bootstrap_compiler/out/vyxc.exe
```

以原生 AOT、`-O0` 和 `-O2` 检查：

- 借用函数和方法中的临时对象在语句完成后析构一次。
- 无名表达式、条件和循环中的临时对象清理。
- 参数求值顺序；`&&`、`||` 和 `?:` 的未选择分支不执行。
- `?:` 仅移动选中的局部对象，未选择对象仍由原作用域析构。
- 返回、局部绑定、消费参数和条件结果中的所有权转移。
- 不同泛型实例的析构绑定，以及 `std.vio.Task<T>` 临时对象和 await 路径。
- 同一程序中的普通及嵌套 `Vec` 克隆与 `Ref` 共享句柄；析构实例化扩容 HIR 表后，MIR 继续使用更新后的表。
- `Box` / `Ref` 的 `deref()` 借用和 `get()` 克隆；返回临时智能指针的借用必须报错。
- `Vec` 中拥有资源的对象在替换、清空、缩小和销毁时析构一次；填充、扩容中的重复元素分别克隆。
- `Vec<str>`、`Box<str>`、`Ref<str>` 及嵌套容器中的堆字符串在替换、缩小、清空和销毁时释放一次；字面量保持非拥有视图。原生计数夹具检查实际分配与释放，覆盖 `string` 兼容拼写。
- 缺少 `Clone` 的拥有资源的类型不能退化为字节复制；原生方法的生命周期不能被同名优化路径绕过。
- 借用整数、普通记录和枚举的克隆读取实际值；指向容器的 `*T` 索引不能误调容器的 `operator[]`。
- 泛型函数转发未绑定的 `T` 时不能选中其他类型的全特化；根命名空间和其他模块的同名泛型与特化必须各自绑定。
- 直接打印堆分配及内联 `String`，并检查实际生成的清理路径。
- 局部 `str` 视图保持临时对象到绑定作用域结束；返回临时对象的借用视图必须报错。

结果及编译器哈希写到本地 `.cache/verification.json`。此门不代表所有借用逃逸分析或异常路径已经覆盖。

这里的值物化针对原生 Vyx 对象。DCI 记录遵守契约的直接构造到最终存储规则，
不经这条路径复制；其异常传播及清理另由 [DCI 异常门](../dci-exceptions/README.md) 验证。
